## Stylization: Disc ID

"Disc ID" is always written with a capital D and capital ID in user-visible
strings — UI text, labels, docs, the spec, error messages — including in the
middle of a sentence ("Ask about this Disc ID again"). Never "disc ID", "disc
id", "discid" or "Disc Id".

Exception: code identifiers (`disc_id`, `DiscIdSignal`) follow language
conventions.
