## Add controls say Add

The person decided how a control that adds an entry to a list reads, inside a
form or an editor such as the release editor:

- Inline beside entries that a field's label already names, the control says "+
  Add". It never repeats the label, and it is never a bare + with no words.
- On a line of its own, the control names what it adds: "+ Add label", "+ Add
  barcode".

In a pane's or a list's header, a bare + is fine when the header's title already
names what the + adds, as the side pane's Playlists tab does. Screen readers
hear the control's name, such as "New playlist…".
