## Add controls say Add

Anywhere in the apps, a control that adds an entry to a list is a + with words,
as the person decided:

- Inline beside entries that a field's label already names, it says "+ Add". It
  never repeats the label, and it is never a bare + with no words.
- On a line of its own, it names what it adds: "+ Add label", "+ Add barcode".
